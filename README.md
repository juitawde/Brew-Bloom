# ☕ Brew & Bloom Café

A pastel-themed, semantic HTML5 café website featuring a full-width video hero section, clean navigation, and multimedia integration. This project demonstrates the use of modern HTML structure, responsive layout concepts, and aesthetic UI design suitable for a real-world café website.

---

## 🌸 Project Overview

**Brew & Bloom Café** is a static website built using **HTML5 and CSS3** that showcases a cozy café experience. The website includes multiple pages such as Home, About, Brews, Specials, and Contact, all structured using semantic HTML elements for better readability, accessibility, and SEO.

A hero video section enhances the visual appeal while pastel colors and elegant typography reflect a calm café aesthetic.

---

## 🧩 Features

- Semantic HTML5 structure (`header`, `nav`, `main`, `section`, `footer`)
- Full-width hero video with overlay text and logo
- Pastel-themed UI design
- Responsive navigation bar
- Multiple linked pages
- Image cards with hover effects
- Clean and readable typography
- Beginner-friendly code structure

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Google Fonts**
- **VS Code**
- **Modern Web Browsers (Chrome, Edge, Firefox)**
